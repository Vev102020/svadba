Проект представляет собой веб‑приложение для просмотра и загрузки фото‑ и видеоконтента. Данный проект был реализован для моей свадьбы с целью получить фото и видео о мероприятии на мой ноутбук (Windows 10) локально, так как все гости сидят в разных соц. сети и нельзя их объединить в одну группу. На сайте наши имена и фотографии заменены на демонстрационные данные.

## Особенности проекта

**Локальный доступ:** проект рассчитан на работу в локальной сети (LAN). Это позволяет открывать сайт на разных устройствах (телефон, планшет, ноутбук) в рамках одной Wi‑Fi‑сети.
**Разделение стека:** бэкенд на Go отвечает за API, раздачу статики и обработку загрузок; фронтенд на Vue 3 (Vite) обеспечивает удобный интерфейс.
**Хранение файлов:** загруженные медиафайлы сохраняются в отдельные папки (`uploads` — общая галерея, `quest` — материалы фотоквеста).
**Отсутствие внешних зависимостей:** проект не требует установки СУБД или сторонних облачных хранилищ; все данные хранятся в файловой системе в JSON файле.

## Стек технологий

**Backend:** Go, стандартная библиотека `net/http`, маршрутизация.
**Frontend:** Vue 3, Vite, JavaScript.
**Сборка:** `go build` для бэкенда, `npm run build` для фронтенда.
**Сеть:** работа через локальный IP‑адрес и порт.

## Как запустить проект

### Подготовка

1.  Скачайте репозиторий и откройте папку проекта в **Visual Studio Code**.

### Сборка и запуск бэкенда

1.  Откройте терминал в VS Code (`Ctrl + ~`).
2.  Соберите сервер для Windows 10:

    go build -o server.exe main.go

3.  Запустите сервер:
    *   Windows: `./server.exe`
4.  **Важно:** при первом запуске система может запросить разрешение на доступ к частной сети (брандмауэр). Обязательно выберите **«Разрешить»** или **«Частная сеть»**, иначе другие устройства не смогут подключиться.

### Сборка фронтенда

1.  Откройте **второй терминал** в VS Code.
2.  Установите зависимости npm install
3.  Перейдите в папку фронтенда:
   
    cd frontend
    
4.  Соберите фронтенд:

    npm run build

### Определение адреса и доступ с других устройств

1.  Узнайте свой локальный IP‑адрес:
    *   Windows: в командной строке выполните `ipconfig` и найдите строку `IPv4 Address` (например, `192.168.0.100`).
      
2.  По умолчанию сервер слушает порт `8080`. Полный адрес для доступа будет выглядеть так:
    ```
    http://192.168.0.100:8080
    ```
3.  Подключитесь к **той же Wi‑Fi‑сети**, что и компьютер с запущенным сервером.
4.  Откройте указанный URL в браузере на любом устройстве (телефон, планшет, другой ПК).

## Работа с медиафайлами

После запуска вы можете загружать фотографии и видео через интерфейс сайта. Файлы автоматически сохраняются в соответствующие папки:

`uploads/` — общая галерея (фото и видео). Для загрузки нажмите + в правом нижнем углу, откроется модельное окно.
`quest/` — материалы фотоквеста. Нажмите на карточку с нужным квестом/заданием и загрузите фото или видео

Убедитесь, что у процесса сервера есть права на запись в эти директории.

## Возможные проблемы и решения

**Не удаётся подключиться с другого устройства:** проверьте, что оба устройства в одной Wi‑Fi‑сети и брандмауэр разрешил доступ к приложению.
**Порт 8080 занят:** измените порт в коде `main.go` (переменная `addr`) и перезапустите сервер.
**Ошибки сборки фронтенда:** убедитесь, что вы находитесь в папке `frontend` и выполнили `npm install` перед `npm run build`.
**Загрузка долгая файла** Файл имеет большой вес.
